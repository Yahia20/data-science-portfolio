# 🌐 Global Internet Usage Analysis (2000–2023)

## 📊 Overview
This project explores global internet usage patterns from 2000 to 2023. Using Python data science tools, we analyze and visualize trends, identify global disparities, and apply clustering to group countries based on internet adoption.

## 💡 Objectives
- Clean and process internet usage data
- Visualize trends by country and continent
- Cluster countries using KMeans and hierarchical methods
- Create interactive and static visualizations

## 📁 Files
- `internet_analysis.ipynb`: Main analysis notebook
- `internet_usage.csv`: Raw dataset
- `requirements.txt`: List of Python packages
- `images/`: Folder with saved plots and charts

## 🔍 Key Insights
- Internet usage increased significantly from 2000 to 2023
- Europe leads in adoption, Africa lags behind
- Clustering revealed distinct groups of countries based on usage
- Strong linear growth with divergence in the past 5 years

## 🧰 Tools & Libraries
- Python, Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- Scikit-learn (KMeans, Clustering)
